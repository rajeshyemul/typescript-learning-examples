# 00 – Setup and Foundations

This section explains what TypeScript is, why it exists, and how it fits into the JavaScript ecosystem.

Before writing TypeScript code, it is important to understand:
- What problems TypeScript solves
- How TypeScript relates to JavaScript
- How TypeScript code is compiled and executed

This folder is intentionally **concept-heavy and code-light**.

By the end of this section, you should be comfortable:
- Setting up TypeScript locally
- Understanding compiler errors
- Running a TypeScript file end-to-end

### How to run the example
- tsc 07_cli_first_file.ts
- node 07_cli_first_file.js
