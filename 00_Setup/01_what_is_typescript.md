# What is TypeScript?

TypeScript is a **superset of JavaScript**.

This means:
- Every valid JavaScript program is also valid TypeScript
- TypeScript adds extra features on top of JavaScript

The most important feature TypeScript adds is **static typing**.

Static typing helps:
- Catch errors while writing code
- Make code easier to understand
- Improve maintainability in large projects

TypeScript code is **compiled** into JavaScript.
Browsers and Node.js run JavaScript, not TypeScript.
