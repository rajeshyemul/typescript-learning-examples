# 05 – Functions

Functions describe behavior in TypeScript.

TypeScript adds strong typing to functions so that:
- inputs are validated
- outputs are predictable
- incorrect usage is caught early

In this section, you will learn:
- how to type function parameters and return values
- optional and default parameters
- rest parameters
- arrow functions
- function overloading
- function types
- higher-order functions

Functions are where TypeScript delivers the most everyday value.
