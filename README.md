# typescript-learning-examples
A structured, example-driven guide to learning TypeScript from basics to advanced concepts, with clear explanations and real-world examples.

This repository is a **step-by-step, example-driven guide** to learning TypeScript from fundamentals to advanced concepts.

It is designed for developers who:
- Know basic JavaScript
- Want to understand TypeScript properly (not just syntax)
- Prefer clear explanations with practical examples
- Want a structured learning path instead of scattered tutorials

---

## Why this repository?

Most TypeScript resources either:
- Jump too quickly into advanced syntax, or
- Explain features without explaining *why they exist*

This repository focuses on:
- Building strong foundations
- Understanding TypeScript’s type system gradually
- Learning how TypeScript improves real-world JavaScript code
- Writing safer, more maintainable code

---

## How this repository is organized

Each folder represents **one stage of learning**.

The structure moves from:
1. Core concepts and setup  
2. Types and type inference  
3. Functions, interfaces, and classes  
4. Generics, utility types, and advanced types  
5. Modules and real-world patterns  

Every folder contains:
- A README explaining concepts in simple language
- Focused `.ts` example files
- Small practice tasks to reinforce learning

---

## Learning Path

00_Setup → What TypeScript is and how it works
01_Basics → Variables, operators, first type safety
02_Types → Primitive and object types, inference
03_Combining_Types → Unions, aliases, keyof
04_Narrowing → Making types safer at runtime
05_Functions → Typed functions and patterns
06_Interfaces → Modeling data and contracts
07_Classes_OOP → Object-oriented TypeScript
08_Generics → Reusable and flexible types
09_Decorators → Metadata and advanced patterns
10_Utility_Types → Built-in helpers for real projects
11_Advanced_Types → Mapped, conditional, recursive types
12_Modules → Structuring large TypeScript projects


---

## How to use this repository

1. Clone the repository
2. Start from `00_Setup`
3. Read the README in each folder
4. Run and modify the example files
5. Complete the small practice tasks before moving on

This repository is meant to be followed **in order**.

---

## Prerequisites

- Basic JavaScript knowledge
- Node.js installed
- Willingness to experiment and break things while learning

No prior TypeScript experience is required.

---

## Who this is for

- JavaScript developers moving to TypeScript
- QA / Automation engineers using TypeScript (Playwright, Cypress, etc.)
- Backend or frontend developers who want stronger type safety
- Anyone who wants to *understand* TypeScript, not just use it
