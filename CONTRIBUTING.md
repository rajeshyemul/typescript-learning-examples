# Contributing to TypeScript Learning Examples

Thank you for your interest in contributing.

This repository is designed as a structured learning resource for TypeScript.
Contributions are welcome as long as they keep the content clear, accurate, and beginner-friendly.

---

## What you can contribute

- Improve explanations or examples
- Add new examples that fit the existing structure
- Fix mistakes or typos
- Suggest better learning flow or structure
- Add small practice tasks

---

## Before you start

For significant changes:
- Please open an issue first to discuss the idea
- This helps avoid duplication and keeps the learning flow consistent

---

## Contribution guidelines

- Follow the existing folder order (00_Setup → 12_Modules)
- Keep examples focused and simple
- Avoid unnecessary complexity
- Add comments explaining *why*, not just *what*
- Prefer clarity over cleverness

---

## Pull request process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Write clear commit messages
5. Submit a pull request referencing the related issue

### Example commit messages

```text
Add example for nullish coalescing operator

Fix typo in type inference explanation

Improve README for 00_Setup section

Add practice tasks for union types

---

## Code of conduct

Be respectful and constructive.
This repository is meant to help people learn.
