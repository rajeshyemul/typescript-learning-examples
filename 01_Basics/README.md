# 01 – Basics

This section introduces the core building blocks of TypeScript.

Here, we focus on how TypeScript adds safety and clarity to:
- Variables
- Common operators
- Everyday JavaScript expressions

The goal is not to learn *all* TypeScript features,
but to start thinking in **types** while writing familiar JavaScript code.
